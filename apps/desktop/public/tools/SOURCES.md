# Tool brand assets

Bundled locally so the tools list works offline. Brand marks belong to their respective owners and identify the installed tools, without implying endorsement.

- `claude-code.svg`: standalone asterisk from [Claude Code's documentation logo](https://mintcdn.com/claude-code/c5r9_6tjPMzFdDDT/logo/light.svg), linked by [the official documentation](https://code.claude.com/docs/en/overview).
- `codex.svg`: transparent OpenAI mark from the header of [OpenAI's Codex documentation](https://developers.openai.com/codex/).
- `grok.svg`: standalone mark from [Grok's official site icon](https://grok.com/images/favicon.svg), without its app-tile background.
- `antigravity.svg`: [Google Antigravity press assets](https://www.antigravity.google/press), [full-color icon](https://www.antigravity.google/assets/image/brand/antigravity-icon__full-color.svg).
- `github.svg`: [GitHub's official site icon](https://github.githubassets.com/favicons/favicon.svg).
