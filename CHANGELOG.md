# Changelog

## 0.1.0

- First desktop and standalone CLI release for macOS, Linux and Windows.
- Coordinates Claude Code, Codex and Antigravity (`agy`) directly through the coding tools and logins already installed on your computer.
- Automatic `petrina` terminal command linking (`petrina` and `petrina mcp`) on desktop startup, plus `petrina update` for standalone CLI installs.
- Quiet daily signed update checks with on-demand download and restart when you choose.
