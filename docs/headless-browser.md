# Agents get a headless browser

Every agent gets an invisible browser with empty storage whenever its conversation opens, including resume, load and a fresh start after reopening fails. Both restart explanations say earlier pages and browser logins are gone.

- Attach Playwright MCP through both connectors' session protocol. Use bundled Chromium headlessly with an isolated profile; never connect to personal Chrome, an extension or an existing browser. Ignore inherited browser debug, remote-service and profile overrides. Disable inherited personal-browser, desktop tools and plugins through connector controls without changing personal settings.
- Keep all browser output in a dedicated temporary folder outside the product working copy. Check that folder before each browser tool runs. Resolve supplied filenames there and refuse anything that is not a real file in that folder: paths outside it, shortcuts (including one whose name stays in the folder but leads through another shortcut), dangling links and shared files. Do not follow a shortcut. Generate and validate filenames for unnamed captures too.
- Builders, testers, both reviewers and the UX designer use this browser for relevant click-throughs, console checks and pictures. Native Mac views use offscreen checks while working in the background. Each of these results allows optional image references with a required, nonempty plain-language caption. Browser-tool pictures are not automatically attachments.
- Before accepting a report or closing its agent, validate each chosen capture as a readable image file genuinely inside that session's folder, without following a shortcut. Copy only validated choices to the unfinished task's separate picture storage outside the repository. Invalid files, outside paths and missing captions use the existing correction flow.
- Store images as separate files while the task is unfinished, including across restarts. Done or cancelled tasks keep captions and report references, with image bytes removed and unavailable. Live events and saved task updates carry only references, captions and their report and agent association. Session loads pictures only near the viewport, releases them offscreen, fits them to the conversation width and shows captions beside the originating report. Reports without images look the same.
- After saving chosen captures, stop the browser and server and remove temporary output and profiles before read-only cleanup or the builder's commit. Failure, pause, cancellation, failed reopening and shutdown clean up too; restart removes interrupted leftovers. No browser evidence enters product changes.

Verify both connectors on every opening path, inherited integrations enabled, independent browser storage, named and unnamed captures, refused outside paths, builder and read-only cleanup, and pictures surviving later stages and restart. Check Session headlessly in light and dark and both demos. Real Claude must open a local page, type, click, read its console and return a valid screenshot, with headless launch recorded and Claude in Chrome absent. Real Codex must also open a local page: connection alone is insufficient; a launch or sandbox failure is an incomplete check. Stop all verification processes. Run the required product checks.

Risks: connector controls vary by version; browser components may need downloading; fresh profiles need test accounts for authenticated checks. Use existing failure and retry handling. No settings screen, hosted service or separate sandbox.
